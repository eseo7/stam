## 기본 확인 항목

작업 성격에 따라 해당 항목에만 체크한다. 해당 없는 항목은 `N/A + 사유`를 기입한다.

- [ ] 페이지 진입 — 지정 URL에서 정상 로딩된다.
- [ ] 핵심 사용자 흐름 — 주요 기능이 의도대로 동작한다.
- [ ] 새로고침 — 새로고침 후 상태가 유지되거나 정상 초기화된다.
- [ ] 권한 — 권한에 따라 접근/기능이 올바르게 제한된다.
- [ ] 빈 상태 — 데이터가 없을 때 Empty State가 표시된다.
- [ ] 오류 상태 — 오류 발생 시 오류 메시지가 표시된다.
- [ ] 모바일/좁은 화면 — 375px 뷰포트에서 레이아웃이 깨지지 않는다.
- [ ] 콘솔 오류 없음 — 브라우저 콘솔에 오류가 없다.

## 최종 판정

- [ ] PASS — 모든 시나리오와 기본 확인 항목을 통과한다.
- [ ] FAIL — 하나 이상의 항목을 통과하지 못한다. 아래에 실패 항목을 명시한다.
- [ ] BLOCKED — 환경 문제로 QA를 완료할 수 없다.
