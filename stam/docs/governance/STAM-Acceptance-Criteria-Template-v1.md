### 범위 (AC-SC)

- [ ] AC-SC-001: 실제 변경 파일이 이번 작업의 수정 허용 범위와 일치한다.

작업 특성에 따른 추가 범위 기준을 사전에 정의한다. 예시:

```
AC-SC-002: 신규 CSS/JS 파일이 생성되지 않는다.          ← 해당 작업에서 신규 파일 생성을 금지한 경우

AC-SC-004: 신규 npm dependency가 추가되지 않는다.
```

위 예시 중 해당하는 항목을 선택하거나 작업 범위에 맞게 새로 정의한다.
